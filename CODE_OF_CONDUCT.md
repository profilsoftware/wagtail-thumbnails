# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and focus on what's best for the project. Harassment, discrimination, and personal attacks aren't tolerated.

Report unacceptable behaviour to `k.matelski1@gmail.com`. Reports are confidential.
